# 功能对接信息生成器 提示词（设计）完整报告
## 报告日期
2026-01-18

## 核心需求
生成一份新的自定义提示词文件，要求：
    1. 用户输入一个功能名称；
    2. 提示词围绕技术栈、接口细节等一般常见的关键信息，不生成文件，而是直接生成结构化的回答，以供前、后端开发人员对接信息。
    3. 智能体需要检索、阅读相关代码，以实现准确的回答。

## 目标文件上下文详情
- 文件路径：app/rag/prompts/feature_info_generator.prompt.md (**提示词正文请直接参考此文件**)
- 文件用途：为前后端开发协作提供“输入功能名称→自动检索代码→输出结构化接口/技术栈关键信息”的AI提示词，便于高效对接。
- 上下文核心：结构化输出、技术栈与接口细节梳理、自动代码检索、适配开发协作场景。
- 适配逻辑：提示词内容严格围绕技术栈、接口、数据模型等开发关键信息，输出格式为Markdown分节，术语统一，便于查阅与对接。

## 设计/优化详情
### 核心设计思路
- 角色定义：定位为“全栈开发助手”，强调代码检索与文档梳理能力，服务于前后端协作。
- 流程拆解：输入功能名称→自动检索相关代码→结构化输出技术栈、接口、数据模型、业务逻辑等关键信息。
- 约束设定：仅基于实际代码输出，结构化、真实、可追溯，杜绝主观推测。

## 输出示例
### 功能名称
用户注册

### 技术栈
- FastAPI（后端框架）
- SQLAlchemy（ORM）
- PostgreSQL（数据库）
- Pydantic（数据校验）

### 主要接口
- 路径：/api/v1/auth/register
- 方法：POST
- 请求参数：
  - username: str
  - password: str
  - email: str
- 响应结构：
  - code: int
  - message: str
  - data: { user_id: int, username: str }
- 鉴权要求：无需登录

### 相关数据模型
- User（models/user.py）
  - id: int
  - username: str
  - password_hash: str
  - email: str

### 关键业务逻辑说明
- 检查用户名/邮箱唯一性
- 密码加密存储
- 注册成功后返回用户基本信息

### 其他注意事项
- 密码长度需大于8位
- 邮箱格式需合法

## 使用指南
- 适用场景：
  - 前后端开发对接接口、梳理技术栈与数据模型
  - 新成员快速了解功能实现细节
  - 技术文档自动生成辅助
- 调整建议：
  - 如需适配特定业务场景，可调整输出分节顺序或增减内容（如安全要求、异常处理等）
  - 保持术语与项目实际一致
- 常见问题：
  - 功能名称不明确：请输入与实际实现相符的功能名称
  - 输出内容不全：请检查代码实现是否规范、注释完整
