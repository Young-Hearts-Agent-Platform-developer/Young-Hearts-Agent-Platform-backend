## 功能概述
本计划分阶段实现基于 LangChain 的 RAG（Retrieval-Augmented Generation）能力，覆盖极简 AI 问答、知识库检索、引用溯源、兜底机制、多角色 prompt 配置与安全运维等。

---

## Phase 1：极简 RAG 问答 API（异步流式，情景 prompt，openai sdk，LangChain 封装）

### 目标
- 实现 /chat/ask 路由，支持异步流式返回，情景 prompt 配置，API Key 环境变量化
- openai sdk + LangChain 封装，FastAPI 异步流式接口，prompt json 配置

### 修改文件清单
|文件路径|修改类型|说明|
|---|---|---|
|app/rag/service.py|新增/编辑|异步封装 openai sdk，集成 LangChain，支持流式与非流式|
|app/api/v1/routes/chat.py|新增|FastAPI 路由，POST /chat/ask，异步流式返回，鉴权|
|app/rag/prompts/|新增|json 格式 prompt 配置|
|.env|新增/编辑|ARK_API_KEY|

### 具体变更
- 新建/完善 app/rag/service.py，异步集成 openai sdk，LangChain 封装，支持流式与非流式，加载 prompt 配置
- 新建 app/api/v1/routes/chat.py，定义 POST /chat/ask，异步流式返回，需登录鉴权，参数含 query、role、reasoning_effort
- 新建 app/rag/prompts/，存放情景 prompt（如 counselor.json、friend.json）
- .env 增加 ARK_API_KEY

### 成功标准
- 自动验证：
  - 路由 POST /chat/ask 需登录，未登录返回 401
  - 登录后可提交 {query, role}，返回 LLM 生成答案（非流式）
  - 不同 role 返回内容风格有差异（可人工检查）
- 手动验证：
  - 用 Postman/前端登录后访问 /chat/ask，切换不同 role，答案风格切换
  - 未登录访问 /chat/ask，返回 401

## Phase 2：知识库检索集成（RAG Pipeline 基础）

### 目标
- 集成向量数据库（如 Chroma），实现知识库检索与上下文拼接，支持引用内容返回

### 修改文件清单
|文件路径|修改类型|说明|
|---|---|---|
|app/knowledge/ingest.py|新增/编辑|知识文档 ingest、embedding、入库|
|app/knowledge/retriever.py|新增/编辑|检索接口，集成 LangChain Retriever|
|app/rag/service.py|编辑|RAG pipeline 集成知识库检索与上下文拼接|
|requirements.txt|编辑|如需补充 chromadb、pgvector 等依赖|

### 具体变更
- ingest 脚本实现文档切片、embedding、入库
- retriever 封装向量检索接口
- rag service 支持检索+生成链路

### 成功标准
- 自动验证：/chat/ask 返回内容含知识库引用片段
- 手动验证：输入知识库相关问题，答案引用知识库内容

### 修改文件清单

|app/api/v1/routes/chat.py|编辑|兜底提示、工单自动生成接口预留|

### 具体变更
- 低置信度时返回兜底提示，API 支持人工转接预留

### 成功标准
- 自动验证：无相关知识时返回兜底内容
- 手动验证：人工输入冷门问题，API 正确兜底
