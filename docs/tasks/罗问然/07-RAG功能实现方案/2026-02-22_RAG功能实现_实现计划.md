## 功能概述
实现基于 LangChain 和 ChromaDB 的 RAG（检索增强生成）功能。主要包括两条主线：
1. **数据入库流**：通过 Celery 异步任务处理文档，根据风险分级进行定制化切片，调用 Doubao-embedding-large 模型进行向量化，并存入 ChromaDB。
2. **检索问答流**：在用户提问时，使用 `ParentDocumentRetriever` 进行“子块召回+父块补全”，设置 0.6 的相似度阈值作为兜底机制，组装包含参考来源的 Prompt，调用大模型生成回答。

## Phase 2: 文档切片与异步入库流

### 目标
实现基于风险分级的定制化切片策略，并编写 Celery 异步任务完成文档的解析、切片、向量化和入库。

### 修改文件清单
|文件路径|修改类型|说明|
|---|---|---|
|app/services/rag/splitters/custom_splitter.py|新增|实现高/中/低风险文档的定制化切片逻辑|
|app/tasks/knowledge_tasks.py|修改|实现 `process_knowledge_document` Celery 任务|
|app/services/knowledge_service.py|修改|在文档创建后触发 Celery 任务|

### 具体变更
1. **`app/services/rag/splitters/custom_splitter.py`**:
   - 实现针对高风险文档的严格结构切片（100-1024 token）。
   - 实现针对中风险文档的混合分层切片（父块 512-2048 token，子块 128-512 token）。
   - 实现针对低风险文档的语义切片（64-512 token）。
   - 确保切片时附加标准化元信息（风险等级、适用年龄等）。
2. **`app/tasks/knowledge_tasks.py`**:
   - 编写 `process_knowledge_document(doc_id: int)` 任务。
   - 流程：从 MySQL 读取文档元数据 -> 根据风险等级调用对应的 Splitter -> 存入 ChromaDB（对于中风险文档，需适配 `ParentDocumentRetriever` 的底层存储结构，如使用 `InMemoryStore` 或 Redis 存储父文档，ChromaDB 存储子文档向量） -> 更新 MySQL 状态为“已发布”或“失败”。
3. **`app/services/knowledge_service.py`**:
   - 在文档上传/创建成功后，调用 `process_knowledge_document.delay(doc.id)`。

### 成功标准
- 自动验证：编写单元测试，验证不同风险等级的文档能被正确切片，且元数据完整。
- 手动验证：通过 API 上传一份测试文档，观察 Celery Worker 日志，确认文档被成功切片并存入 ChromaDB，MySQL 状态更新为“已发布”。

## Phase 3: 检索问答流与 RAG 引擎集成

### 目标
实现带有兜底机制和溯源能力的检索问答链，并集成到现有的 RAG 服务入口中。

### 修改文件清单
|文件路径|修改类型|说明|
|---|---|---|
|app/services/rag/chains/rag_chain.py|新增|构建基于 `ParentDocumentRetriever` 的检索问答链|
|app/services/rag/rag_service.py|修改|重构 `async_chat_with_rag`，接入 RAG 链|
|app/services/rag/prompts/rag_prompt.json|新增|定义包含上下文和来源要求的 Prompt 模板|

### 具体变更
1. **`app/services/rag/chains/rag_chain.py`**:
   - 初始化 `ParentDocumentRetriever`（连接 ChromaDB 和文档存储）。
   - 实现检索逻辑：获取 Top-K 相关片段，计算相似度得分。
   - 增加兜底逻辑：若最高相似度低于 0.6，直接返回预设的转人工提示。
   - 组装上下文：将检索到的文档片段及其元数据（来源、页码等）拼接成字符串。
2. **`app/services/rag/rag_service.py`**:
   - 修改 `async_chat_with_rag` 函数。
   - 调用 `rag_chain.py` 中的检索逻辑获取上下文。
   - 将上下文注入到 Prompt 中，调用 `ChatOpenAI` 生成流式回答。
3. **`app/services/rag/prompts/rag_prompt.json`**:
   - 新增 RAG 专用的 Prompt 模板，明确要求 LLM 基于提供的上下文回答，并在回答末尾附带参考来源。

### 成功标准
- 自动验证：编写单元测试，模拟检索结果，验证相似度低于 0.6 时触发兜底机制；验证 Prompt 组装正确。
- 手动验证：通过聊天接口提问，确认回答准确、包含参考来源，且在提问无关内容时能触发转人工提示。
