## 功能概述

实现智能体咨询会话相关的后端接口与服务，包括会话创建、历史会话列表、消息详情、流式对话（SSE），并补充数据模型、schemas、service 层，完善权限控制与消息持久化。

---

## Phase 1: 数据模型与 Schemas 补充

### 目标
新增 `ConsultationSession` 和 `ConsultationMessage` 的 ORM models 与 Pydantic schemas，支持用户身份关联。

### 修改文件清单

|文件路径|修改类型|说明|
|---|---|---|
|app/models/consultation.py|新增|定义 ConsultationSession/Message ORM|
|app/schemas/consultation.py|新增|定义 Pydantic schemas|
|app/models/__init__.py|更新|导入新模型|
|app/schemas/__init__.py|更新|导入新 schema|
|docs/“心青年”智能体平台-数据模型与 API 设计.md|参考|参考数据模型设计定义模型|

### 具体变更
- ConsultationSession: id, user_id, topic, created_at, is_archived
- ConsultationMessage: id, session_id(与 ConsultationSession 的 id 关联), role, content, sources, created_at
- schemas 与 models 字段保持一致，支持 from_orm。

### 成功标准
- 自动验证：pytest 新建模型与 schema 测试用例通过
- 手动验证：数据库可正常迁移并插入/查询 session/message

## Phase 2: Service 层实现

### 目标
实现会话与消息的 service 层，包括创建、查询、持久化、权限校验。

### 修改文件清单

|文件路径|修改类型|说明|
|---|---|---|
|app/services/consultation_service.py|新增|会话与消息管理服务|
|app/services/__init__.py|更新|导入新服务|

### 具体变更
- create_session(user_id, topic)
- list_sessions(user_id, roles, page, size)
- get_session_detail(session_id, user_id, roles)
- save_message(session_id, role, content, sources)
- 权限校验：普通用户仅能访问自己的，管理员可全量访问
- 管理员判定：roles 字段包含 'admin' 即为管理员

### 成功标准
- 自动验证：service 层单元测试通过
- 手动验证：可通过 service 层正常创建/查询/保存数据

## Phase 3: API 路由补充与权限控制

### 目标
补充 RESTful API 路由，完善 `/api/consult/chat`，实现会话创建、列表、详情接口，支持 session_id 参数与权限校验。

### 修改文件清单

|文件路径|修改类型|说明|
|---|---|---|
|app/api/v1/routes/consult.py|更新|补充/调整 API 路由|
|app/rag/service.py|更新|AI回复持久化逻辑|
|app/services/auth.py|更新|补充管理员判定逻辑|

### 具体变更
- POST `/api/consult/sessions` 创建会话
- GET `/api/consult/sessions` 历史会话列表（分页）
- GET `/api/consult/sessions/:id` 会话消息详情
- POST `/api/consult/chat` 增加 session_id 参数，AI回复写入 ConsultationMessage
- 权限校验：普通用户仅能访问自己的，管理员可全量访问
- 分页参数标准：`page`（页码，默认1），`size`（每页数量，默认20，最大100）

### 成功标准
- 自动验证：pytest 路由测试用例通过
- 手动验证：前端可正常调用各接口，权限控制有效

完善 `/api/consult/chat` 流式输出，AI回复实时写入 ConsultationMessage，异常兜底与重试。

### 修改文件清单

|文件路径|修改类型|说明|
|---|---|---|
|app/rag/service.py|更新|AI回复持久化、异常处理|

### 具体变更

- AI回复实时写入 ConsultationMessage，保留原始 sources 字段
- 异常兜底，消息写入失败重试

### 成功标准
- 自动验证：流式接口测试用例通过
- 手动验证：AI回复可实时持久化，异常可兜底
